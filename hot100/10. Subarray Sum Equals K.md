# 10. Subarray Sum Equals K

- **题目 : [560. 和为 K 的子数组](https://leetcode.cn/problems/subarray-sum-equals-k/)**

> 难度: 中等
>
> 标签: 数组, 哈希表, 前缀和

## 解法一

> 子数组是数组中元素的连续非空序列。
>
> 一开始我排序后用滑动窗口...错了

- **注意: 连续非空**

所以不能用sort去排序

---

- 思路
  1. 定义一个map去存储**前缀和**和**前缀和出现的次数**
     - 比如`map.get(j)` 表示 `nums[0]`一直加到`nums[j]`的值
  2. `map.get(j) - map.get(i) = k --> map.get(i) = map.get(j) - k `
  3. 所以, 假设我们当前的前缀和为`preSum`, 我们只需要去map里面查找`preSum - k`这个**前缀和**是否存在, 存在的话就`ret`加上这个**前缀和的次数**

**AC代码:**

```java
class Solution {
    public int subarraySum(int[] nums, int k) {
        // key:前缀和  val:前缀和出现的次数
        Map<Integer, Integer> map = new HashMap<>();
        //初始化map
        map.put(0, 1);
        int ret = 0;
        
        // preSum用来记录当前前缀和
        int preSum = 0;
        for(int num : nums) {
            preSum += num;
            // 如果preSum - k存在，说明存在连续子串
            if(map.containsKey(preSum - k)) {
                ret += map.get(preSum - k);
            }
            // 把当前前缀和put进map里
            map.put(preSum, map.getOrDefault(preSum, 0) + 1);
        }
        return ret;
    }
}
```

- **时间复杂度：O(n)**

  只遍历数组一遍，HashMap 的查找和插入都是 O(1)。

- **空间复杂度：O(n)**

  最坏情况下所有前缀和都不同，map 中存 n 个键值对。

# 11. Sliding Window Maximum

- **题目 : [239. 滑动窗口最大值](https://leetcode.cn/problems/sliding-window-maximum/)**

> 难度: 困难
>
> 标签: 队列, 数组, 滑动窗口, 单调队列, 堆(优先队列), 区间最值查询

## 解法一

- **思路:**
  1. 创建一个大根堆,里面的每个元素都是一个`int`数组,**索引 0 存放数值,索引 1 存放nums中的下标**
  2. 滑动窗口时便向堆里加元素
  3. 删除时不需要考虑堆里面的元素满不满足 k 个
  4. 只看堆顶元素的下标是否在窗口内便可, 不在窗口内便`poll()`

**AC代码:**

```java
class Solution {
    public int[] maxSlidingWindow(int[] nums, int k) {
        int n = nums.length;
        int[] ret = new int[n - k + 1];
        // 大根堆维护滑动窗口最大值
        PriorityQueue<int[]> maxHeap = new PriorityQueue<>((a, b) -> b[0] - a[0]);

        // 先把第一个窗口k个元素入堆
        for (int i = 0; i < k; i++) {
            maxHeap.offer(new int[]{nums[i], i});
        }
        // 第一个窗口的最大值
        ret[0] = maxHeap.peek()[0];

        // 开始滑动窗口，i是窗口右边界
        for (int i = k; i < n; i++) {
            // 新元素入堆
            maxHeap.offer(new int[]{nums[i], i});

            // 延迟删除, 堆顶下标小于窗口左边界 i‑k+1，说明已经滑出窗口，扔掉
            while (maxHeap.peek()[1] < i - k + 1) {
                maxHeap.poll();
            }

            // 当前窗口最大值写入结果数组
            ret[i - k + 1] = maxHeap.peek()[0];
        }
        return ret;
        
    }
}
```

- **时间复杂度：O(n·log n)**

  每个元素入堆一次、出堆最多一次，堆操作 O(log n)，总 O(n·log n)。

- **空间复杂度：O(n)**

  堆中最多同时有 n 个元素（含延迟删除、还没弹出的过期元素）。

## 解法二

- 思路见注释

**AC代码:**

```java
class Solution {
    public int[] maxSlidingWindow(int[] nums, int k) {
        int n = nums.length;
        int[] ret = new int[n - k + 1];
        // 双端队列
        // deque 保存下标，nums[deque] 数值递减
        Deque<Integer> deque = new ArrayDeque<>();
        
        // i为滑动窗口右边界
        for (int i = 0; i < n; i++) {
            // 新元素进来：把队尾 小于等于 新元素的全部移除，维持递减
            while (!deque.isEmpty() && nums[i] >= nums[deque.peekLast()]) {
                deque.pollLast();
            }
            deque.offerLast(i);

            // 队头下标滑出窗口左边界，弹出队头
            int left = i - k + 1;
            while (deque.peekFirst() < left) {
                deque.pollFirst();
            }

            // 窗口成型 i >= k‑1，开始记录答案
            if (i >= k - 1) {
                ret[left] = nums[deque.peekFirst()];
            }
        }
        return ret;
    }
}
```

- **时间复杂度：O(n)**

  每个下标最多入队一次、出队一次，均摊 O(1)。

- **空间复杂度：O(k)**

  双端队列里最多同时存窗口内的 k 个元素（结果数组不计）。

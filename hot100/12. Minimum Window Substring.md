# 12. Minimum Window Substring

- **题目 : [76. 最小覆盖子串](https://leetcode.cn/problems/minimum-window-substring/)**

> 难度: 困难
>
> 标签: 哈希表, 字符串, 滑动窗口

## 解法一

主要思路就是滑动窗口的时候用map去存储目标字符的数量, 一旦数量达标, 收缩窗口并开始计算最短长度

- 思路见注释

**AC代码:**

```java
class Solution {
    public String minWindow(String s, String t) {
        Map<Character,Integer> tMap = new HashMap<>();
        Map<Character,Integer> sMap = new HashMap<>();
        // 将目标字符串存入tMap
        for(char ch : t.toCharArray()) {
            tMap.put(ch,tMap.getOrDefault(ch,0) + 1);
        }
        // 用valid记录当前合格的字符数
        int valid = 0;
        int left = 0;
        int right = 0;
        String ret = "";
        // 记录长度最小值
        int minLen = Integer.MAX_VALUE;
        // 记录最小值的起始下标
        int idx = 0;
        
        // i表示窗口右边界
        for(right = 0; right < s.length(); right++) {
            // 获取当前遍历到的字符
            char ch = s.charAt(right);
            // 判断是否存在于tMap中
            if(tMap.containsKey(ch)) {
                // 存入sMap中
                sMap.put(ch, sMap.getOrDefault(ch,0) + 1);
                // 如果此时sMap的这个字符刚好等于tMap这个字符的数量，vaild + 1
                if(sMap.get(ch).equals(tMap.get(ch))) {
                    valid++;
                }
            }
            // 当vaild满足要求时，开始收缩左窗口
            while(valid == tMap.size()) {
                // 记录长度当前值
                int curLen = right - left + 1;
                if(curLen < minLen) {
                    minLen = curLen;
                    idx = left;
                }
                
                char sch = s.charAt(left);
                if(tMap.containsKey(sch)) {
                    if(sMap.get(sch).equals(tMap.get(sch))) {
                        valid--;
                    }
                    sMap.put(sch,sMap.get(sch) - 1);
                }
                left++;                
            }                        
        }
        if(minLen != Integer.MAX_VALUE) {
            ret = s.substring(idx, idx + minLen);
        }
        return ret;
    }
}
```

- **时间复杂度：O(m + n)**

  m 为 t 的长度，n 为 s 的长度。开头遍历 t 构造 tMap 是 O(m)；滑动窗口里 right、left 各自最多移动 n 次，map 操作 O(1)，所以总共 O(m + n)。（本质是线性：每个输入都只遍历常数次）

- **空间复杂度：O(1)**

  两个 map 最多存字符集大小个键值对（本题只含大小写字母，可视为常数）。

# 5. Container With Most Water

- **题目 : [11. 盛最多水的容器](https://leetcode.cn/problems/container-with-most-water/)**

> 难度: 中等
>
> 标签: 贪心, 数组, 双指针

## 解法一

> 这道题最简单的方法就是双层循环去搞定,当然了,这样效率太低了

我们可以考虑用 **双指针** 去解决, 具体思路如下👇

1. 定义**左指针left**指向数组首位, 定义**右指针right**指向数组末位

2. 明确面积公式 `S = (right - left) * Math.min(height[left], height[right])`

3. 每次移动指针都要重新计算一遍面积

- 如何移动指针?

这里可以贪心策略, 每次移动**高度小**的那个指针, 毕竟根据公式, 面积要求的是俩个指针高度最小的那个

> 这种贪心策略是可行的

AC代码:

```java
class Solution {
    public int maxArea(int[] height) {
        int ret = 0;
        int len = height.length;
        int left = 0;
        int right = len - 1;

        while(left < right) {
            // 先计算面积
            ret = Math.max(ret, calArea(left, right, height));
            // 移动指针(贪心策略: 优先移动高度小的)
            if(height[left] <= height[right]) {
                left++;
            }else {
                right--;
            }
        }
        return ret;
    }
    // 计算面积
    // S = (right - left) * Math.min(height[left], height[right])
    int calArea(int left, int right, int[] height) {
        return (right - left) * Math.min(height[left], height[right]);
    }
}
```

- **时间复杂度：O(n)**

  左右指针每次向中间靠拢一步，最多移动 n 次，每次计算面积为 O(1)。

- **空间复杂度：O(1)**

  原地操作，只用到常数个额外变量。

## 解法一(略微优化版)

- 我们可以稍微做个剪枝,如果**left后面的高度小于等于当前高度 --> 直接跳过(right同理)**

AC代码

```java
class Solution {
    public int maxArea(int[] height) {
        int ret = 0;
        int len = height.length;
        int left = 0;
        int right = len - 1;

        while(left < right) {
            // 先计算面积
            ret = Math.max(ret, calArea(left, right, height));
            // 移动指针
            if(height[left] <= height[right]) {
                int cur = height[left];
                // 对于left: 后面的高度小于等于当前left高度，直接跳过去，不用算面积
                while(left < right && height[left] <= cur){
                    left++;
                }
            }else {
                int cur = height[right];
                // 同理, 对于right: 前面的高度小于等于当前right高度, 直接跳过 
                while(left < right && height[right] <= cur){
                    right--;
                }
            }
        }
        return ret;
    }
    // 计算面积
    // S = (right - left) * Math.min(height[left], height[right])
    int calArea(int left, int right, int[] height) {
        return (right - left) * Math.min(height[left], height[right]);
    }
}
```

- **时间复杂度：O(n)**

  虽然加了内层 while 跳过，但左右指针总移动次数仍然不超过 n，每个元素最多被跳过一次，因此整体仍是 O(n)。

- **空间复杂度：O(1)**

  原地操作，只用到常数个额外变量。

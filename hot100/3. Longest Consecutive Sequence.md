# 3. Longest Consecutive Sequence

- **题目 : [128. 最长连续序列](https://leetcode.cn/problems/longest-consecutive-sequence/)**

> 难度: 中等
>
> 标签: 并查集, 数组, 哈希表

## 解法一

> 请你设计并实现时间复杂度为 `O(n)` 的算法解决此问题。

- 可以看到, 他需要时间复杂度为 `O(n)` 的算法

- 因此我们无法对数组进行sort排序后来找最长,详见 [**数组常用API**](java刷题常用API/数组常用API.md) 的`复杂度对照` 部分

其次我们可以发现, 重复的元素不影响最长序列, 如示例3

> **示例 3：**
>
> ```java
> 输入：nums = [1,0,1,2]
> 输出：3
> ```

那么我们可以考虑用 **set集合** 来去重实现这个题目.

详见 [**Set常用API**](java刷题常用API/Set常用API.md)

- 可以先把数据存入set集合中,然后遍历set集合
- 当num - 1不存在时, while循环找最长序列, 当num - 1存在时, 跳过

AC代码

```java
class Solution {
    public int longestConsecutive(int[] nums) {
        int ret = 0;
        Set<Integer> set = new HashSet<>();

        //第一次遍历把数据存入set里面
        for(int num : nums) {
            set.add(num);
        }

        //第二次遍历找连续最长序列
        for(int num : set) {
            //当 num - 1 不存在时,才是序列起点
            if(!set.contains(num - 1)) {
                int curNum = num;
                int count = 0;
                //开始往后数
                while(set.contains(curNum)) {
                    count++;
                    curNum++;
                }
                //取最大的
                ret = Math.max(ret, count);
            }   
        }
        return ret;
    }
}
```

- **时间复杂度：O(n)**

  虽然有两层循环（外层遍历 set，内层 while 向后找连续元素），但每个元素最多只会被内层 while 访问一次，因此总的时间复杂度是 O(n)。

- **空间复杂度：O(n)**

  最坏情况下所有元素都存入 HashSet，占用 O(n) 空间。

- **可能会有疑问,为什么要 num - 1 不存在时, 才是序列起点**

因为如果 **num - 1** 存在, 那么以 **num - 1** 为起点的序列一定比 **num** 为起点的序列长

如下:

```java
int[] nums = [0,0,2,3,4,5,7]
//假设当前遍历到的num为3
// num - 1 = 2 (2存在于 nums 中)
// 2,3,4,5 肯定长于 3,4,5 
//所以要当num - 1不存在时才把num当作序列起点
```

```java
class Solution {
    public int longestConsecutive(int[] nums) {
        int n = nums.length;
        if (n < 2) return n;

        // 1. 找最小最大值
        int min = nums[0], max = nums[0];
        for (int i = 1; i < n; i++) {
            if (nums[i] < min) min = nums[i];
            else if (nums[i] > max) max = nums[i];
        }
        long range = (long) max - min + 1;

        // 2. 密集数据：布尔数组标记
        if (range <= n * 10L && range <= Integer.MAX_VALUE) {
            byte[] present = new byte[(int) range];
            for (int num : nums) {
                present[num - min] = 1;
            }
            int maxLen = 0, currLen = 0;
            for (byte b : present) {
                if (b == 1) {
                    currLen++;
                } else {
                    maxLen = Math.max(maxLen, currLen);
                    currLen = 0;
                }
            }
            return Math.max(maxLen, currLen);
        }

        // 3. 稀疏数据：开放寻址哈希表
        int capacity = 2;
        while (capacity < n * 2) capacity <<= 1;
        int mask = capacity - 1;
        int[] keys = new int[capacity];
        byte[] states = new byte[capacity]; // 0=空,1=占用

        int uniqueCount = 0;
        for (int num : nums) {
            int idx = (num & mask); // 直接用低位哈希，更快
            while (states[idx] == 1) {
                if (keys[idx] == num) break;
                idx = (idx + 1) & mask;
            }
            if (states[idx] == 0) {
                states[idx] = 1;
                keys[idx] = num;
                nums[uniqueCount++] = num; // 覆盖原数组存去重值
            }
        }

        int maxLen = 0;
        for (int i = 0; i < uniqueCount; i++) {
            int num = nums[i];
            // 只从连续序列的最小值开始
            if (!contains(keys, states, mask, num - 1)) {
                int len = 1;
                while (contains(keys, states, mask, num + len)) {
                    len++;
                }
                maxLen = Math.max(maxLen, len);
                if (maxLen > uniqueCount / 2) return maxLen; // 剪枝
            }
        }
        return maxLen;
    }

    private boolean contains(int[] keys, byte[] states, int mask, int num) {
        int idx = (num & mask);
        while (states[idx] == 1) {
            if (keys[idx] == num) return true;
            idx = (idx + 1) & mask;
        }
        return false;
    }
}
```

# 3. Longest Consecutive Sequence

- **题目 : [128. 最长连续序列](https://leetcode.cn/problems/longest-consecutive-sequence/)**

> 难度: 中等
>
> 标签: 并查集, 数组, 哈希表

## 解法一

> 请你设计并实现时间复杂度为 `O(n)` 的算法解决此问题。

- 可以看到, 他需要时间复杂度为 `O(n)` 的算法

- 因此我们无法对数组进行sort排序后来找最长,详见 [**数组常用API**](java刷题常用API/数组常用API.md) 的`复杂度对照` 部分

其次我们可以发现, 重复的元素不影响最长序列, 如示例3

> **示例 3：**
>
> ```java
> 输入：nums = [1,0,1,2]
> 输出：3
> ```

那么我们可以考虑用 **set集合** 来去重实现这个题目.

在HashSet中查询效率为  O(1) ,非常适合这道题目, 详见 [**Set常用API**](java刷题常用API/Set常用API.md)

- 可以先把数据存入set集合中,然后遍历set集合
- 当num - 1不存在时, while循环找最长序列, 当num - 1存在时, 跳过

AC代码

```java
class Solution {
    public int longestConsecutive(int[] nums) {
        int ret = 0;
        Set<Integer> set = new HashSet<>();

        //第一次遍历把数据存入set里面
        for(int num : nums) {
            set.add(num);
        }

        //第二次遍历找连续最长序列
        for(int num : set) {
            //当 num - 1 不存在时,才是序列起点
            if(!set.contains(num - 1)) {
                int curNum = num;
                int count = 0;
                //开始往后数
                while(set.contains(curNum)) {
                    count++;
                    curNum++;
                    //取最大的
                    ret = Math.max(ret, count);
                }
            }   
        }
        return ret;
    }
}
```

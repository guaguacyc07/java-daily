# 3. Big Countries

- **题目 : [595. 大的国家](https://leetcode.cn/problems/big-countries/)**

> 难度: 简单
>
> 标签: 数据库

## 解法一

- 两个条件用 `or` 直接连起来就行
- 这题的两个字段都非空，不会踩 `NULL` 的坑，所以不用像 584 那样补 `is null`

```sql
select 
    name, population, area 
from 
    World 
where 
    area >= 3000000 
    or population >= 25000000
```

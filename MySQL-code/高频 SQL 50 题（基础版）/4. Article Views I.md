# 4. Article Views I

- **题目 : [1148. 文章浏览 I](https://leetcode.cn/problems/article-views-i/)**

> 难度: 简单
>
> 标签: 数据库

## 解法一

- 条件：`author_id = viewer_id` 表示作者看了自己的文章
- 一个作者可能看了多篇，所以要 `distinct` 去重
- 给 `author_id` 起别名 `id`（题目要求输出列名是 `id`），最后按 `id` 升序

```sql
select distinct
    author_id id 
from 
    Views
where 
    author_id = viewer_id
order by 
    id asc
```

# 2. Find Customer Referee

- **题目 : [584. 寻找用户推荐人](https://leetcode.cn/problems/find-customer-referee/)**

> 难度: 简单
>
> 标签: 数据库

## 解法一

- 注意 `referee_id != 2` 会把 `referee_id` 为 `NULL` 的行过滤掉
  - 因为在 SQL 里 `NULL != 2` 的结果是**未知(unknown)**，不是 true，`WHERE` 只保留结果为 true 的行
- 所以要额外加一个 `referee_id is null` 把没推荐人的顾客也捞回来

```sql
select name from Customer where referee_id != 2 or referee_id is null
```

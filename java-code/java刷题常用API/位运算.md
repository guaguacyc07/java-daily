# 位运算 写题笔记

> 刷题默认对 `int`（32 位）操作，涉及大范围时记得用 `long`（64 位）。
>
> AI生成+人工优化

## 一、运算符速查

| 运算符 | 含义 | 例子 |
| ---- | ---- | ---- |
| `&` | 与：两位都是 1 才是 1 | `6 & 3 = 2`（`110 & 011 = 010`） |
| `|` | 或：有一位是 1 就是 1 | `6 | 3 = 7` |
| `^` | 异或：相同 0，不同 1 | `6 ^ 3 = 5` |
| `~` | 取反（含符号位） | `~5 = -6` |
| `<<` | 左移，右边补 0（≈×2） | `1 << 3 = 8` |
| `>>` | 算术右移，**保留符号位** | `-8 >> 1 = -4` |
| `>>>` | 无符号右移，高位补 0 | `-8 >>> 1` 很大（正数） |

## 二、必须背下来的套路

```java
// 1. 判奇偶
if ((n & 1) == 1) { /* 奇数 */ }        // 比 n % 2 快，且负数也能用

// 2. 乘 / 除 2（2 的幂）
n << 1;      // ×2
n >> 1;      // ÷2（负数向下取整，注意）

// 3. 交换两数（炫技，日常还是用临时变量）
a ^= b; b ^= a; a ^= b;

// 4. 取最低位的 1（lowbit，树状数组核心）
int lowbit = n & (-n);                  // 如 12(1100) → 4(0100)

// 5. 去掉最低位的 1
n = n & (n - 1);                        // 12(1100) → 8(1000)

// 6. 判断 2 的幂
boolean isPowerOfTwo = n > 0 && (n & (n - 1)) == 0;

// 7. 数二进制 1 的个数
int cnt = 0;
while (n != 0) { n &= (n - 1); cnt++; } // 有几个 1 就循环几次
// 或者直接：Integer.bitCount(n);

// 8. 第 k 位（从 0 开始）的操作
(x >> k) & 1;        // 取出第 k 位
x | (1 << k);        // 第 k 位置 1
x & ~(1 << k);       // 第 k 位置 0
x ^ (1 << k);        // 翻转第 k 位
```

## 三、异或的三大性质（记住！）

1. `x ^ x = 0`（和自己异或是 0）
2. `x ^ 0 = x`（和 0 异或不变）
3. 满足交换律、结合律 → `a ^ b ^ a = b`

**经典应用：**

```java
// 只出现一次的数字（其余都成对出现）：全部异或
int res = 0;
for (int x : nums) res ^= x;      // 成对的都消成 0，剩那个落单的
```

> 进阶（LeetCode 260，两个落单的）：全部异或得到 `a ^ b`，取其 lowbit 把数组分成两组，各自异或即可。

## 四、高频题型套路

### 1. 不用 `+ -` 做加法（LeetCode 面试高频）

```java
int add(int a, int b) {
    while (b != 0) {
        int carry = (a & b) << 1;   // 进位
        a = a ^ b;                  // 本位和
        b = carry;
    }
    return a;
}
```

### 2. 子集枚举 / 状态压缩（mask 遍历）

```java
int n = 3;  // 集合大小
for (int mask = 0; mask < (1 << n); mask++) {
    // 判断第 i 个元素在不在当前子集
    if ((mask & (1 << i)) != 0) { ... }
}
// 全 1 集合： (1 << n) - 1
```

### 3. 字符小技巧

```java
// 大小写字母互转：A=65, a=97，ASCII 差 32，即差一个二进制位 0x20
char lower = (char) ('A' | 32);     // 'a'
char upper = (char) ('a' & ~32);    // 'A'
char flip   = (char) (ch ^ 32);     // 直接翻转大小写

// 用 int 的 26 位表示字母集合（判重复、交集很快）
int seen = 0;
seen |= 1 << (ch - 'a');            // 标记字母出现
```

### 4. 汉明距离（两数二进制位不同的个数）

```java
int count = Integer.bitCount(x ^ y);  // 异或后数 1 的个数
```

## 五、常见坑

1. **运算符优先级**：`&` / `^` / `|` 比 `==`、`!=` 低！
   `(n & 1) == 0` 必须加括号，否则会先算 `1 == 0` 再按位与。
2. **移位别越界**：`int` 只有 32 位，`1 << k` 当 k ≥ 31 会出问题；要 `long` 就用 `1L << k`。
3. **负数 `>>` 和 `>>>` 不同**：`>>` 保留符号位（负数右移还是负数），`>>>` 无脑补 0。
4. **取反与补码**：`~x = -x - 1`，`-x = ~x + 1`。
5. **判断 2 的幂先判正**：`n & (n-1) == 0` 对 0 也成立，要加 `n > 0`。
6. **`n & (n - 1)` 只对正整数消位**：负数场景少，别硬套。

## 六、复杂度

- 单次位运算都是 **O(1)**；
- 数 1 个数用 `n & (n-1)` 循环是 **O(二进制中 1 的个数)**（最多 32 次，常数级），`Integer.bitCount` 也是 O(1)。

# 13. Maximum Subarray

- **题目 : [53. 最大子数组和](https://leetcode.cn/problems/maximum-subarray/)**

> 难度: 中等
>
> 标签: 数组, 分治, 动态规划

## 解法一

> 说实在的,这题我属实是写不出用分治

- **动态规划**

**思路:**

1. 动态规划只需要弄清楚**状态**和**状态转移方程**便基本写完了
2. 状态: `dp[i]`表示以 `nums[i]` 为结尾的最大子数组和
3. 为什么是这个状态呢?  
   - 因为我们的目标就是找到最大子数组和, 只要找个dp[i]中的最大值便可以找到答案
4. 状态转移方程`dp[i] = max(dp[i-1] + nums[i], nums[i])`

**AC代码:**

```java
class Solution {
    public int maxSubArray(int[] nums) {
        int n = nums.length;
        int[] dp = new int[n + 10];
        
        // dp[i]是以nums[i]结尾的最大子数组和
        // 状态转移方程dp[i]=max(dp[i-1]+nums[i],nums[i])
        
        // 初始化dp数组
        dp[0] = nums[0];
        int ret = nums[0];
        for(int i = 1; i < n; i++) {
            dp[i] = Math.max(dp[i - 1] + nums[i], nums[i]);
            // 同步记录最大值
            ret = Math.max(ret, dp[i]);
        }
        return ret;
    }
}
```

- **时间复杂度：O(n)**

  只遍历一遍数组，每个状态 dp[i] 由 dp[i-1] 与 nums[i] O(1) 推出，总共 O(n)。

- **空间复杂度：O(n)**

  dp 数组占用 O(n) 存储空间（`new int[n + 10]`，+10 只是防越界缓冲，不影响量级）。

## 解法二

- **贪心算法**

**思路:**

1. 见注释

**AC代码:**

```java
class Solution {
    public int maxSubArray(int[] nums) {
        int n = nums.length;
        // 要连续
        // 那么只要我当前总和加起来大于0那我就一直加进去
        // 一旦小于0就重新计算总和(贪心)
        int ret = Integer.MIN_VALUE;
        int sum = 0;
        
        for(int i = 0; i < n; i++) {
            sum += nums[i];
            ret = Math.max(ret, sum);
            // 小于0则重新计算总和
            if(sum < 0) {
                sum = 0;
            }
        }        
        return ret;
    }
}
```

- **时间复杂度：O(n)**

  只遍历一遍数组，每个元素只处理一次。

- **空间复杂度：O(1)**

  只用了 ret、sum 等常数个变量。

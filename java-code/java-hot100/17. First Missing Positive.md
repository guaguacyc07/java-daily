# 17. First Missing Positive

- **题目 : [41. 缺失的第一个正数](https://leetcode.cn/problems/first-missing-positive/)**

> 难度: 困难
>
> 标签: 数组, 哈希表

## 解法一

**思路:**

核心就是**把每个数放到它该在的位置**，模拟一遍：

```java
// nums = [1, 4, 3, -3]   n = 4
// 目标：让每个值 v 待在下标 v - 1 的位置（即 nums[i] == i + 1）
// 遍历 i = 0 ~ n - 1，把在 [1, n] 内的数不断换到它该待的位置
//
// i = 0：nums[0] = 1，该待下标 0，nums[0] 已经是 1 → 不动
// i = 1：nums[1] = 4，该待下标 3，nums[3] = -3 ≠ 4 → 交换
//        换完变成 [1, -3, 3, 4]，此时 nums[1] = -3 不在 [1, n] → 跳过
// i = 2：nums[2] = 3，该待下标 2，nums[2] 已经是 3 → 不动
// i = 3：nums[3] = 4，该待下标 3，nums[3] 已经是 4 → 不动
//
// 换完后再扫一遍：i = 1 期望 nums[1] == 2，实际是 -3 → 缺失的第一个正数是 2
```

**特殊情况：**

- 重复值如 `[1, 1]`：1 的目标位置已经存了 1，如果不判断 `nums[nums[i] - 1] != nums[i]`，1 和 1 会无限交换 → 死循环
- 不在 `[1, n]` 的数（`<= 0` 或 `> n`）：它们不可能是答案，放着不动或被动换走就行
- 如果 1 ~ n 全部就位：第二遍扫完没提前返回，最后返回 `n + 1`（比如 `[1, 2, 3]` → 4）

**AC代码:**

```java
class Solution {
    public int firstMissingPositive(int[] nums) {
        int n = nums.length;
        
        for(int i = 0; i < n; i++) {
            // 1.判断是否在[1， n]范围内
            //(因为数组索引从0开始，要减1，所以是1到n范围)
            // 2.判断这个数字的目标位置，是否已经存了相同的值(防止[1, 1]这种情况从而进入死循环)
            // nums[nums[i] - 1] != nums[i]
            while(1 <= nums[i] && nums[i] <= n && nums[nums[i] - 1] != nums[i]) {
                swap(nums, i);            
            }
        }
        for(int i = 0; i < n; i++) {
            if(nums[i] != i + 1) {
                return i + 1;
            }
        }
        return n + 1;
        
    }
    void swap(int[] nums, int idx) {
        int temp = nums[idx];
        nums[idx] = nums[temp - 1];
        nums[temp - 1] = temp;
    }
}
```

- **时间复杂度：O(n)**

  每个数最多被换到正确位置一次，`while` 里总交换次数 ≤ n，整体均摊 O(n)。

- **空间复杂度：O(1)**

  原地交换，只用常数个变量。

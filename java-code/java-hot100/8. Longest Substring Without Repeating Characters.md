# 8. Longest Substring Without Repeating Characters

- **题目 : [3. 无重复字符的最长子串](https://leetcode.cn/problems/longest-substring-without-repeating-characters/)**

> 难度: 中等
>
> 标签: 中级工程师, 哈希表, 字符串, 滑动窗口

## 解法一

> 我用的是set加queue做的, 有点慢

- **思路: **

1. 遍历字符串`s`的每个字符,
2. 查看是否存在于 **set** 中, 如果存在则不断将队头出队列, 如果不存在则添加
3. 记得 **set** 里面也要删除 

**AC代码: **

```java
class Solution {
    public int lengthOfLongestSubstring(String s) {
        // 创建队列
        Queue<Character> queue = new ArrayDeque<>();
        // 创建哈希表查看是否有重复
        Set<Character> set = new HashSet<>();

        int ret = 0;
        for(int i = 0; i < s.length(); i++) {
            // 遍历字符串每个字符
            char ch = s.charAt(i);
            // 如果这个字符存在于set里面, queue一直poll到不存在为止
            while(set.contains(ch)) {
                char curCh = queue.poll();
                set.remove(curCh);
            }
            // 添加新的元素
            queue.offer(ch);
            set.add(ch);

            ret = Math.max(ret, queue.size());
        }
        return ret;
    }
}
```

- **时间复杂度：O(n)**

  每个字符最多入队一次、出队一次，set 增删查都是 O(1)，总 O(n)。

- **空间复杂度：O(n)**

  queue 和 set 最坏存 n 个字符。

> 分析: 也许用双指针来代替queue维护最长子串可能可以更快

## 解法二

**AC代码:** 

```java
class Solution {
    public int lengthOfLongestSubstring(String s) {
        // set：保存当前滑动窗口内出现过的字符，用来判重
        Set<Character> set = new HashSet<>();
        // 将字符串转为字符数组，减少charAt方法调用，提高效率
        char[] str = s.toCharArray();
        // 记录无重复字符子串的最大长度
        int ret = 0;
        // 滑动窗口左边界
        int left = 0;
        // right为滑动窗口右边界，不断向右扩大窗口
        for(int right = 0; right < str.length; right++){
            // 当前右指针指向的字符
            char ch = str[right];
            // 如果当前字符已经存在窗口内，不断收缩左边界，直到窗口无重复
            while(set.contains(ch)){
                // 移除窗口最左侧字符
                set.remove(str[left]);
                // 左边界右移，缩小窗口
                left++;
            }
            // 将当前字符加入窗口集合
            set.add(ch);
            // 更新最大子串长度
            ret = Math.max(ret, right - left + 1);
        }
        return ret;
    }
}
```

- **时间复杂度：O(n)**

  `right` 和 `left` 各自最多移动 n 次，set 增删查都是 O(1)，总 O(n)。

- **空间复杂度：O(n)**

  set 最坏存 n 个字符。

# 16. Product of Array Except Self

- **题目 : [238. 除了自身以外数组的乘积](https://leetcode.cn/problems/product-of-array-except-self/)**

> 难度: 中等
>
> 标签: 前缀和

## 解法一

> 请 **不要使用除法，**且在 `O(n)` 时间复杂度内完成此题。

> 题目数据 **保证** 数组 `nums`之中任意元素的全部前缀元素和后缀的乘积都在 **32 位** 整数范围内。

**思路:**

- 定义一个**前缀积数组 pre[] **和一个**后缀积 suf[] **数组
- 那么 `answer[i] = pre[i - 1] * suf[i + 1]`
-  然后再额外补充 `answer[0]` 和 `answer[n - 1]`即可

**AC代码:**

```java
class Solution {
    public int[] productExceptSelf(int[] nums) {
        int n = nums.length;
        // 前缀乘积数组
        int[] pre = new int[n];
        // 后缀乘积数组
        int[] suf = new int[n];
        
        int sum = 1;
        for(int i = 0; i < n; i++) {
            sum *= nums[i];
            pre[i] = sum; 
        }
        sum = 1;
        for(int i = n - 1; i >= 0; i--) {
            sum *= nums[i];
            suf[i] = sum;
        }

        for(int i = 1; i < n - 1; i++) {
            nums[i] = pre[i - 1] * suf[i + 1];
        }
        nums[0] = suf[1];
        nums[n - 1] = pre[n - 2];
        return nums;
    }
}
```

- **时间复杂度：O(n)**

  前缀积、后缀积各扫一遍，最后再扫一遍填答案，共 3 趟线性遍历。

- **空间复杂度：O(n)**

  额外使用了 pre、suf 两个长度 n 的数组；进阶可做到 **O(1) 额外空间**：答案数组直接当 pre 复用，suf 用一个滚动变量从右往左累计即可。

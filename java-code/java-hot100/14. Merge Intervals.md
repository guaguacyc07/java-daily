# 14. Merge Intervals

- **题目 : [56. 合并区间](https://leetcode.cn/problems/merge-intervals/)**

> 难度: 中等
>
> 标签: 数组, 排序, 快速排序

## 解法一

**思路**

1. 大概思路看注释
2. 注意以下情况
   - `[[1, 4], [1, 4]]`
   - `[[1, 4], [2, 3]]`
3. 我们每次遍历的时候, 看是否能合并
   - **如果可以合并**, 那么直接把当前数组索引 0 的值赋值给下个数组索引 0 
   - 也就是`intervals[i + 1][0] = intervals[i][0];`
   - **如果不能合并**, 那么直接把当前数组加入 ret 中保存结果

**AC代码:**

```java
class Solution {
    public int[][] merge(int[][] intervals) {
        int n = intervals.length;
        List<int[]> ret = new ArrayList<>();
        // 对二维数组内每个一维数组按下标0的数字大小进行排序
        Arrays.sort(intervals, (a, b) -> a[0] - b[0]);
        // 提示说明: intervals[i].length == 2
        // 所以我们遍历每个数组, 比较当前数组下标1的数字和下个数组下标0的数字
        // 然后分情况处理即可
        for(int i = 0; i < n; i++) {
            // 如果 now[1](intervals[0][1]) >= next[0](intervals[1][0]) 则准备合并
            if(i < n - 1 && intervals[i][1] >= intervals[i + 1][0]) {
                // 防止出现 [1, 4] [2, 3] 这种情况
                if(intervals[i][1] <= intervals[i + 1][1]) {
                    intervals[i + 1][0] = intervals[i][0];
                } else {
                    intervals[i + 1] = intervals[i];
                }                         
            } else {
                ret.add(intervals[i]);
            }
        }
        return ret.toArray(new int[ret.size()][]);
    }
}
```

> // 原写法（有溢出风险）
> `Arrays.sort(intervals, (a, b) -> a[0] - b[0]);`
>
> // 优化后（安全无溢出）
> `Arrays.sort(intervals, (a, b) -> Integer.compare(a[0], b[0]));`

- **时间复杂度：O(n·log n)**

  排序占 O(n·log n)；合并阶段只需一趟遍历 O(n)。总时间复杂度 O(n·log n)。

- **空间复杂度：O(n)**

  结果列表 `ret` 最坏存放 n 个区间；Java 对对象数组排序（TimSort）另需 O(n) 辅助空间。

## 解法一(优化写法)

```java
class Solution {
    public int[][] merge(int[][] intervals) {
        int n = intervals.length;
        if (n == 0) return new int[0][0];
        
        List<int[]> ret = new ArrayList<>();
        // 按左端点升序排序，安全无溢出
        Arrays.sort(intervals, (a, b) -> Integer.compare(a[0], b[0]));
        
        for (int i = 0; i < n; i++) {
            // 判断是否能和下一个区间合并
            if (i < n - 1 && intervals[i][1] >= intervals[i + 1][0]) {
                // 合并：左端点取当前的，右端点取最大值
                intervals[i + 1][0] = intervals[i][0];
                intervals[i + 1][1] = Math.max(intervals[i][1], intervals[i + 1][1]);
            } else {
                // 不能合并，当前区间已是最终状态，加入结果
                ret.add(intervals[i]);
            }
        }
        return ret.toArray(new int[ret.size()][]);
    }
}
```

- **时间复杂度：O(n·log n)**

  与解法一相同：排序 O(n·log n) + 一趟合并 O(n)。

- **空间复杂度：O(n)**

  与解法一相同：结果列表最坏存 n 个区间（排序辅助空间另算）。

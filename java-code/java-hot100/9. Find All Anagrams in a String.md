# 9. Find All Anagrams in a String

- **题目 : [438. 找到字符串中所有字母异位词](https://leetcode.cn/problems/find-all-anagrams-in-a-string/)**

> 难度: 中等
>
> 标签: 哈希表, 字符串, 滑动窗口

## 解法一

- 思路

1. 滑动一个长度和目标字符串p长度相同的窗口
2. 然后用map算滑动窗口的字符串和目标字符串是否为异位词便可

```java
class Solution {
    public List<Integer> findAnagrams(String s, String p) {
        List<Integer> ret = new ArrayList<>();
        // 创建map计数p的字符
        Map<Character, Integer> pMap = new HashMap<>(); 
        // 遍历p字符串
        char[] pch = p.toCharArray();
        for(char ch : pch) {
            pMap.put(ch, pMap.getOrDefault(ch, 0) + 1);
        }

        // 用双指针滑动窗口
        int left = 0;
        int right = 0;
        // 创建map计数s的字符
        Map<Character, Integer> sMap = new HashMap<>(); 
        char[] sch = s.toCharArray();

        while(right < sch.length) {
            // 如果滑动窗口长度大于目标p的长度,左指针右移
            while(right - left + 1> p.length()) {
                sMap.put(sch[left], sMap.get(sch[left]) - 1);
                // 计数为0时要remove这个key
                sMap.remove(sch[left], 0);
                left++;
            }    
            // 把当前right位置的字符加入sMap
            sMap.put(sch[right], sMap.getOrDefault(sch[right], 0) + 1);
            // 然后判断是否是异位词
            if(right-left+1 == p.length()){
                if(sMap.equals(pMap)){
                    ret.add(left);
                }
            }
            right++;
        }
        return ret;
    }
}
```

- **时间复杂度：O(n)**

  左右指针各自最多移动 n 次，`Map.equals` 在窗口大小固定、且只含小写字母（最多 26 个 key）时是 O(1)，总 O(n)。

- **空间复杂度：O(1)**

  两个 map 最多存 26 个小写字母的计数。

## 解法二

使用数组优化,代替了哈希

```java
class Solution {
    public List<Integer> findAnagrams(String s, String p) {
        List<Integer> res = new ArrayList<>();
        int[] pcot = new int[26];
        int[] scot = new int[26];
        // 记录p的字符数组
        for (int i = 0; i < p.length(); i++) {
            pcot[p.charAt(i) - 'a']++;
        }
        // 无解情况
        if (s.length() < p.length()) {
            return res;
        }
        // 遍历s
        int left = 0;
        int right = 0;
        while (right < s.length()) {
            // 右指针字符加入窗口计数
            scot[s.charAt(right) - 'a']++;

            // 窗口长度超过p的长度，收缩左边界
            // 窗口实际长度 [left,right] = right - left + 1
            while (right - left + 1 > p.length()) {
                // 移出窗口最左侧字符，计数减1
                scot[s.charAt(left) - 'a']--;
                left++;
            }

            // 当前窗口大小正好等于p的长度，对比数组
            if (right - left + 1 == p.length()) {
                if (Arrays.equals(pcot, scot)) {
                    res.add(left); // 窗口左边界就是异位词起始下标
                }
            }
            right++;
        }
        return res;
    }
}
```

- **时间复杂度：O(n)**

  左右指针各移动 n 次，`Arrays.equals` 比较长度 26 的数组是 O(1)，总 O(n)。

- **空间复杂度：O(1)**

  两个长度 26 的计数数组。

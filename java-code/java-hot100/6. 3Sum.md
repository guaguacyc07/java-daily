# 6. 3Sum

- **题目 : [15. 三数之和](https://leetcode.cn/problems/3sum/)**

> 难度: 中等
>
> 标签: 数组, 双指针, 排序

## 解法一

> **注意：**答案中不可以包含重复的三元组。

**思路:**

1. **数组先排序**, 排序是为了方便去重和使用双指针
2. 固定第一个数 **nums[i]** , 然后用双指针找另外俩个数, 满足 `nums[left] + nums[right] = -nums[i]` 

3. 左右指针定义为 `left = i + 1` , `right = nums.length - 1` (只在 **i** 的右边搜索)

- 左右指针这样定义的原因 (只在 **i** 的右边搜索的原因):

```java
// 已排序的nums数组
nums = [-1, -1, 0, 0, 1, 2];

//首先我们可以看出,答案应该是[-1, -1, 2]和[-1, 0, 1] 
//我们假设当前i遍历到了2也就是对应nums中第一个0的位置
[-1, -1, 0, 0, 1, 2];
		 i
//如果left你要从0开始向右找答案,那会出现一个问题---答案重复
[-1, -1, 0, 0, 1, 2];
  L      i     R
//也许你会说,可以left在向右遍历的时候可以跳过相同元素(是的,这样没问题)
//但是会有另一种情况
[-1, -1, 0, 0, 1, 2];
  i      L     R
//这个答案便重复了,所以我们只需要从i的右边找答案,就可以找到全部答案,并且不重复
```

4. 定义好 `left` 和 `right` 后, 便计算 `sum` 
   - `sum = nums[left] + nums[right]`
   - sum < target：left 右移，变大
   - sum > target：right 左移，变小
   - sum == target：找到一组解，保存结果，移动指针并去重

**AC代码:**

```java
class Solution {
    public List<List<Integer>> threeSum(int[] nums) {
        List<List<Integer>> ret = new ArrayList<>();
        // 先对原始数组排序,方便去重
        Arrays.sort(nums);

        int n = nums.length;
        for(int i = 0; i < n; i++) {
            // i位置去重
            if(i > 0 && nums[i] == nums[i - 1]) {
                continue;
            }

            int left = i + 1;
            int right = n - 1;
            int target = -nums[i];

            while(left < right) {
                int sum = nums[left] + nums[right];
                if(sum == target) {
                    ret.add(Arrays.asList(nums[i], nums[left], nums[right]));
                    // left去重
                    while(left < right && nums[left] == nums[left + 1]) {
                        left++;
                    }
                    // right去重
                    while(left < right && nums[right] == nums[right - 1]) {
                        right--;
                    }
                    left++;
                    right--;
                } else if(sum < target) {
                    left++;
                } else {
                    right--;
                }
            }
        }
        return ret;
    }
}
```

- **时间复杂度：O(n²)**

  排序 O(n·log n)，外层固定第一个数 O(n)，内层双指针 O(n)，整体为 O(n²)。

- **空间复杂度：O(1)**

  不计返回结果列表；`Arrays.sort` 内部递归栈空间为 O(log n)。

# 4. Move Zeroes

- **题目 : [283. 移动零](https://leetcode.cn/problems/move-zeroes/)**

> 难度: 简单
>
> 标签: 数组, 双指针

## 解法一

> **请注意** ，必须在不复制数组的情况下**原地**对数组进行操作。

- 用双指针解决, 在**每次循环**中 **left** 去指向遇到的一个0, **right** 去指向遇到的第一个非0
- 当满足 **`right < n && left < right`** 的时候交换

效果演示👇

```java
int[] nums = [0,1,2,0,3]

// 1 初始时
[0,1,2,0,3]
 L
 R
// 2 R指针向后移动一格
[0,1,2,0,3]
 L
   R    
// 3 满足条件,交换nums[L]和nums[R],并且L和R都往后移动(R不管是否交换都要移动)
[1,0,2,0,3]
   L 
     R 
// 4 满足条件,交换nums[L]和nums[R],并且L和R都往后移动(R不管是否交换都要移动)   
[1,2,0,0,3]
     L 
       R     
// 5 L满足指向0,不动, R向后移动
[1,2,0,0,3]
     L 
         R       
// 6 结束   
[1,2,3,0,0]
     L 
         R     
```

- 那么为什么不管是否交换 **R** 都要移动呢?

原因如下👇(结合AC代码理解)

```java
nums = [1, 0]，n = 2

1. 初始 left=0, right=0
2. 内层 left 循环：nums[0]=1≠0，left++ -> left = 1
3. 内层 right 循环：nums[0]=1≠0，条件nums[right]==0不成立，right 保持 0，不变化
4. 判断交换条件：left(1) < right(0) -> false, 不交换, 也不会进入 if 里面, right 没有机会自增
5. 外层回到 while(right < n) -> right=0 < 2, 继续循环
```

AC代码:

```java
class Solution {
    public void moveZeroes(int[] nums) {
        // 左指针指向遇到的第一个0 
        // 右指针指向遇到的第一个非0数
        int left = 0;
        int right = 0;
        int n = nums.length;

        while(right < n) {
            // 先判断left < n, 如果先判断nums[left]的话会索引越界
            while(left < n && nums[left] != 0) {
                left++;
            }
            //同理
            while(right < n && nums[right] == 0) {
                right++;
            }
            // 判断是否满足交换规则
            if(right < n && left < right) {
                int temp = nums[left];
                nums[left] = nums[right];
                nums[right] = temp;
                left++;
            }
            //不管是否交换,都要让right往后移动
            right++;
        }
    }
}
```

- **时间复杂度：O(n)**

  左右指针各自最多移动 n 次，每个元素至多被访问常数次，因此总时间复杂度为 O(n)。

- **空间复杂度：O(1)**

  原地操作，只用到常数个额外变量（`left`、`right`、`n`、`temp`）。

## 解法二

- **不做交换, 做覆盖**

1. 第一遍遍历:  把数组里所有非零元素, 按原有顺序, 从数组头部开始依次覆盖写入, `idx`记录下一个写入位置
2. 遍历结束后, `idx`前面全部是非 0, 从`idx`到数组末尾, 全部赋值为 0

```java
class Solution {
    public void moveZeroes(int[] nums) {
        int idx = 0;
        // 把所有非0依次往前填
        for(int num : nums){
            if(num != 0){
                nums[idx++] = num;
            }
        }
        // 后面全部填0
        while(idx < nums.length){
            nums[idx++] = 0;
        }
    }
}
```

- **时间复杂度：O(n)**

  第一遍 for 遍历把非零元素填到前面，第二遍 while 把剩余位置填零，总共遍历 O(n) 次。

- **空间复杂度：O(1)**

  原地操作，只用到常数个额外变量（`idx`）。

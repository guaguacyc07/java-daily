# 15. Rotate Array

- **题目 : [189. 轮转数组](https://leetcode.cn/problems/rotate-array/)**

> 难度: 中等
>
> 标签: 数组, 数学, 双指针

## 解法一

**思路: **

- 建一个新数组去存答案, 然后再把答案数组重新赋值回去即可

**AC代码:**

```java
class Solution {
    public void rotate(int[] nums, int k) {
        int n = nums.length;
        // 额外建一个数组保存答案
        // 轮转k个位置
        // 所以直接把 n - k % n 后的数字全部放进去
        // 然后剩下的数字按顺序继续往后
        k = k % n;
        int[] ret = new int[n];
        int retIdx = 0;
        for(int i = n - k; i < n; i++) {
            ret[retIdx] = nums[i];
            retIdx++;
        }
        for(int i = 0; i < n - k; i++) {
            ret[retIdx] = nums[i];
            retIdx++;
        }
        for(int i = 0; i < n; i++) {
            nums[i] = ret[i];
        }
    }
}
```

- **时间复杂度：O(n)**

  前两个循环总共拷贝 n 个元素，第三个循环再回写 n 次，总 O(n)。

- **空间复杂度：O(n)**

  额外使用了长度为 n 的数组 ret。

## 解法二

>原地算法

**思路: **

- 给个例子就能看懂了

```java
输入: nums = [1,2,3,4,5,6,7], k = 3
输出: [5,6,7,1,2,3,4]
// 首先我们可以看到,轮转后分为了2个区块
// 区块1 -- [5, 6, 7]  区块2 -- [1, 2, 3, 4]
// 如果我们把这俩个区块都分别反转一次呢?
// 区块1反转后 -- [7, 6, 5]  区块2 -- [4, 3, 2, 1]
// 如果你再给他们合并起来, 你会发现
// [7, 6, 5, 4, 3, 2, 1]
// 他刚好是原数组反转后的结果
// 所以你再反转一次会得到原数组

// 那么对于这道题, 思路就很简单了, 把上述步骤倒着来一遍
```

**AC代码:**

```java
class Solution {
    public void rotate(int[] nums, int k) {
        int n = nums.length;
        k = k % n;
        // 1. 反转原数组
        reverse(nums, 0, n - 1);
        // 2. 反转区块1 [0, k % n - 1]
        reverse(nums, 0, k - 1);
        // 3. 反转区块2 [k % n, n - 1]
        reverse(nums, k, n - 1);
    }
    void reverse(int[] nums, int start, int end) {
        while(start < end) {
            int temp = nums[start];
            nums[start] = nums[end];
            nums[end] = temp;
            start++;
            end--;
        }
    }
}
```

- **时间复杂度：O(n)**

  三次反转，每个元素一共被交换两次，总 O(n)。

- **空间复杂度：O(1)**

  原地反转，只用了常数个临时变量。
